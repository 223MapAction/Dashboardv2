## Ce que fait un mainteneur

- Relire et intégrer les pull requests sur `main`.
- Gérer les secrets du dépôt (`VITE_API_BASE_URL`, `VITE_MAPBOX_TOKEN`).
- Répondre aux signalements de sécurité, selon [SECURITY.md](./SECURITY.md).
- Publier les versions.

## Décisions

Les changements ordinaires passent par une pull request relue par un
mainteneur, avec la CI au vert.

Les décisions qui engagent le projet au-delà du code — licence, identité
visuelle, adresse de l'API de production, ouverture de nouveaux accès —
reviennent à Map Action Mali en tant que détenteur des droits.

## Devenir mainteneur

Les contributions régulières et de qualité mènent naturellement à une
proposition. La décision appartient à Map Action Mali.

Pour contribuer sans être mainteneur, voir
[CONTRIBUTING.md](https://github.com/223MapAction/.github/blob/main/CONTRIBUTING.md).
